Part 1 of 11
Install Python

Python is the programming language the chatbot is built with. You need Python installed to run it — like needing Microsoft Word to open .docx files.

1
Open a Web Browser

Look at the bottom of your screen (the taskbar). Click on Google Chrome 🔵, Microsoft Edge 🔷, or any browser icon.

2
Go to the Python Download Page

Click inside the browser address bar at the top. Delete everything there. Type exactly:

https://www.python.org/downloads/

Press Enter.

3
Download Python

You will see a big yellow button: "Download Python 3.12.x" (number may vary — that is fine).

Click that button. A file downloads to your Downloads folder.

4
Install Python
  1. Open your Downloads folder (folder icon 📁 on taskbar → Downloads on left side)
  2. Find the file named python-3.12.x-amd64.exe — double-click it
  3. A blue/white installer window opens
CRITICAL — Do NOT miss this!
At the bottom of the installer window, you will see a checkbox:
☐ Add Python to PATH
TICK THAT CHECKBOX by clicking on it. If you skip this, nothing will work.
  1. Click the big button: "Install Now"
  2. If Windows asks "Do you want to allow this app to make changes?" — click Yes
  3. Wait 3–5 minutes. When it says "Setup was successful" — click Close
Verify Python installed: Press ⊞ Windows → type cmd → Enter → black window opens → type python --version → press Enter. You should see Python 3.12.x. If so, close the window. ✅

Install Ollama (The AI Engine)

Ollama runs the AI model on your local computer. Think of Ollama as a "player app" and the AI models (downloaded next) as the content it plays.

5
Download Ollama

In your browser, go to:

https://ollama.com/download/windows

Click "Download for Windows". A file called OllamaSetup.exe downloads.

6
Install Ollama
  1. Go to Downloads folder → double-click OllamaSetup.exe
  2. If Windows asks permission — click Yes
  3. Ollama installs automatically (no questions asked)
  4. Look at the bottom-right corner of your screen near the clock — you will see a small 🦙 llama icon
That 🦙 icon = Ollama is running. ✅

7
Open Command Prompt

Press ⊞ Windows key → type cmd → press Enter. The black Command Prompt window opens.

8
Download the Main AI Model

In the black window, type exactly and press Enter:

ollama pull llama3:8b

A progress bar appears. Wait for it to finish and show success. This takes 20–40 minutes.

9
Download the Embedding Model

In the same black window, type and press Enter:

ollama pull mxbai-embed-large

Wait for success. (~5–15 minutes)

10
Confirm Both Models Downloaded
ollama list

You should see both models listed. Close the black window. ✅

Enable Internet Access (Access From Anywhere in the World)

Right now the chatbot only works on the same WiFi. This part makes it accessible from anywhere — 4G, 5G, home internet, abroad — for free using Cloudflare Tunnel.

20
Create a Free Cloudflare Account
  1. Go to: https://cloudflare.com
  2. Click Sign Up → enter your email → create a password
  3. Check your email inbox → click the verification link
  4. You are now logged in to Cloudflare ✅
21
Run the Cloudflare Setup Wizard

Make sure START_SERVER.bat is running. Then go to the backend folder and double-click SETUP_CLOUDFLARE.bat.

The wizard guides you through 4 automatic steps:

Wizard StepWhat HappensWhat You Do
A — Install cloudflaredDownloads the Cloudflare toolJust wait
B — Log in to CloudflareOpens browser for authorizationLog in → click Authorize
C — Create tunnelCreates a secure connectionJust wait
D — Choose URL typeAsks how people will access the botPress 1 or 2 (see below)

Step D — Choosing your URL:

OptionURL ExampleBest For
Press 1 — Random URL (easiest)https://abc123.trycloudflare.comGetting started fast. URL changes on restart.
Press 2 — Your own domainhttps://chat.youruniversity.eduPermanent, professional. Needs your domain.
If you don't own a domain, press 1. You can always upgrade to Option 2 later.

Part 10 of 11
Make the Chatbot Run Automatically 24/7
28
Enable Windows Auto Login
  1. Press ⊞ Windows key + R → type netplwiz → press Enter
  2. Click your username to select it
  3. Uncheck the box: "Users must enter a username and password..."
  4. Click Apply → enter your Windows password → click OK
Now the PC boots straight to the desktop without anyone needing to type a password.
29
Add the Chatbot to Windows Startup
  1. Press ⊞ Windows key + R → type shell:startup → press Enter
    (A special folder opens)
  2. Open a second File Explorer: press ⊞ Windows key + E
    Navigate to the backend folder
  3. Right-click START_SERVER.bat → click "Copy"
  4. Go back to the Startup folder → right-click inside it → "Paste shortcut"
Now every time Windows starts: PC auto-logs in → chatbot starts → Ollama starts → Cloudflare tunnel starts → bot is online within 30 seconds ✅
30
Set PC to Never Sleep
  1. Press ⊞ Windows key → type Power & sleep settings → press Enter
  2. Under "Sleep": Set "When plugged in, sleep after" → Never
  3. Under "Screen": Set "When plugged in, turn off screen after" → Never
