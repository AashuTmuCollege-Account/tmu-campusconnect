🚀 Method 1: One-Click Automated Installer (Recommended)

Everything required to run TMU CampusConnect has been fully automated into a modern, light-themed universal installer.

Step 1: Launch Installer

Double-click ONE_CLICK_INSTALLER.bat in the project directory. The Pristine Light GUI will launch automatically.

Step 2: Click "START ONE-CLICK INSTALLATION & REPAIR"

The installer executes 6 automated diagnostic stages:

  • Stage 1: System Compatibility & Windows RAM verification (12 GB detected).
  • Stage 2: Python 3.12 Engine detection & environment validation.
  • Stage 3: Ollama AI Server daemon check & automatic background startup.
  • Stage 4: Local model verification (llama3.2:3b and mxbai-embed-large).
  • Stage 5: Virtual environment dependency healing via requirements.txt.
  • Stage 6: Preloaded TMU Knowledge Base verification (13 sources, 284 logs).
Step 3: Switch to "Quick Launch & Deploy Hub" Tab

Use the segmented pill bar at the top to access instant launch buttons for the local server, ngrok tunnel, and browser apps.

🌐 Embedding on University Websites & Portals

You can embed the TMU CampusConnect chatbot on any webpage or portal in 3 distinct ways:

Option A: Standard Floating Widget (Every Webpage)

Add this single line before the closing </body> tag of your university website:

<!-- TMU CampusConnect Floating Assistant -->
<script src="https://unstuffed-flyover-answering.ngrok-free.dev/widget/embed.js"></script>

Option B: Left-Docked Portal Embed

For side-panel layouts such as student ERPs or administrative dashboards:

<!-- TMU Left-Docked Embed -->
<script src="https://unstuffed-flyover-answering.ngrok-free.dev/widget/embed-left.js"></script>

Option C: Tampermonkey Userscript (portal2.tmu.ac.in)

To inject the assistant directly onto the live TMU ERP portal without server-side access, install the pre-configured script from widget/tampermonkey-tmu.user.js in the Tampermonkey browser extension.
